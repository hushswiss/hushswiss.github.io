Privacy Policy

Hush Uploader · Last updated: 8 October 2026

1. Scope

Hush Uploader ("the tool") is a private script used solely by the owner of the YouTube channels Swiss Hush and Silent Until It's Not to upload and manage their own videos. It runs locally on the owner's computer. It is not offered to the public and has no other users.

2. YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data the tool accesses

With the permission granted through Google's sign-in (scopes youtube.upload and youtube), the tool accesses only the YouTube account that authorized it, and only the data needed to:

  • upload videos and set their metadata (title, description, tags, privacy status, publish time),
  • set custom thumbnails,
  • add videos to the channel's own playlists,
  • read the upload and processing status of the uploaded videos and basic channel/playlist identifiers.

The tool does not access, collect or process data of any other YouTube user (for example viewers, commenters or subscribers).

4. How data is stored

The OAuth access and refresh tokens and a local upload log are stored only on the owner's own computer. Nothing is sent to any server other than Google's / YouTube's own API endpoints. No cookies, analytics or tracking are used.

5. Sharing

No data is sold, shared with or disclosed to any third party. Data is only transmitted to YouTube as part of the API requests described above.

6. Retention and deletion

Locally stored tokens and logs are kept only as long as the tool is in use and can be deleted by the owner at any time. Videos and metadata on YouTube are governed by YouTube's own settings and policies.

7. Revoking access

Access granted to the tool can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions.

8. Changes

This policy may be updated if the tool changes. The date above shows the latest version.
