Hush Uploader

Private upload tool for the YouTube channels Swiss Hush and Silent Until It's Not.

What it is

Hush Uploader is a small, private command-line script that runs only on the channel owner's own computer. It uses the YouTube Data API to publish the owner's own videos to the two channels named above. It is not a public service: there is no website login, no sign-up and no other users.

What it does

  • Uploads video files to the owner's own YouTube channels
  • Sets titles, descriptions, tags, thumbnails and scheduled publish times
  • Adds uploaded videos to the channels' own playlists
  • Reads the upload and processing status of those videos

The tool only accesses the YouTube channels of the account that authorizes it. It does not access any data of other users.
